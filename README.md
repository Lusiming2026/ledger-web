# 记账本 · 网页版

一个**零依赖、打开即用**的记账网页应用。手机浏览器点开链接就能记账，无需安装 App、无需注册登录。

> 🔗 **在线体验**：https://student-ledger-11588.app.workbuddy.host/

## ✨ 功能

| 模块 | 说明 |
|---|---|
| 📝 记一笔 | 支出 / 收入 / 转账，15 个预置分类（emoji 图标 + 配色），支持日期与备注 |
| 🏠 首页总览 | 总资产、本月收支结余、预算进度条（80% / 100% 变色预警）、账户卡片 |
| 📋 账单列表 | 按日分组、类型 / 月份筛选、点按编辑 / 删除（软删除 + 余额自动回滚） |
| 💳 账户管理 | 现金 / 银行卡 / 微信 / 支付宝，增删归档、**对账**（覆盖余额并留痕） |
| 🎯 预算 | 月度预算、使用率进度、近 6 个月历史 |
| 📊 报表 | 月度收支、支出分类占比、每日收支趋势图 |
| 💾 数据 | CSV 导出（Excel 可直接打开）、**AES-256 加密备份 / 恢复**、一键清空 |

## 📱 使用

1. 手机浏览器打开上方链接即可使用
2. **添加到主屏幕**（iPhone：Safari → 分享 → 添加到主屏幕；安卓：浏览器菜单 → 添加到主屏幕），即可像原生 App 一样全屏使用

## 🔒 数据与隐私

- 数据**只存在你自己的浏览器本地**（localStorage），不上传任何服务器
- 换设备用「加密备份 → 恢复」迁移，AES-256-GCM 加密，密码不对无法解密
- 定期导出加密备份，浏览器清理缓存 / 无痕模式不会保留数据

## 🧱 技术栈

- 纯 HTML + CSS + JavaScript，**单文件零依赖零构建**
- Web Crypto API（AES-256-GCM）加密备份
- 业务规则对齐 Kotlin 原生版 App：金额以「分」存储、转账余额双向联动、软删除回滚、转出 ≠ 转入校验
